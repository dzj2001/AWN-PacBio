### AWN: 基于深度学习的小麦基因组结构变异检测方法（适用于三代测序技术PacBio）
####  一、概述
AWN 是一个基于深度学习的结构变异（SV）检测与基因分型框架，专为六倍体面包小麦基因组设计。

本项目是 Cue 框架（针对二倍体人类基因组开发）的增强版，成功实现了从二倍体到六倍体的跨倍性迁移。针对小麦基因组庞大、重复序列多、亚基因组间信号混杂等挑战，AWN 对 Cue 原有的四阶堆叠沙漏网络进行了三项核心改进，提出 RF-HGNet（Refined Fusion Hourglass Network）：

Dropout 正则化增强：系统性引入 Dropout 层，缓解过拟合，提升泛化能力；

沙漏模块特征融合重构：优化上采样方式（双线性插值+可学习反卷积），重构多尺度特征融合机制，提升小尺度变异定位精度；

余弦退火学习率调度器：替换原有动态学习率策略，配合热重启，实现更稳健的收敛。

AWN 支持检测以下 SV 类型：DEL、DUP、INV、INVDEL、INVDUP。
